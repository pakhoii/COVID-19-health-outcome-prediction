# COVID-19 Health Outcome Prediction
**HCMIU Data Mining Project**

## Project Overview
This project implements a machine learning pipeline designed to predict mortality risk among COVID-19 patients. Utilizing a dataset of over one million records from the Mexican government, the model analyzes demographics, comorbidities, and clinical indicators to identify high-risk individuals early.

## Context & Objective
The COVID-19 pandemic placed extreme pressure on global healthcare systems, creating an urgent need to prioritize limited treatment resources.

*   **The Challenge:** Rapidly distinguishing between patients with mild symptoms and those at risk of severe illness or death in overloaded hospitals.
*   **The Solution:** A data-driven predictive tool that helps medical staff optimize the allocation of scarce resources, such as ICU beds and ventilators.

## Key Features
The model is trained on anonymized patient data to uncover complex patterns in mortality risk, focusing on:
*   **Demographics:** Age, Sex.
*   **Comorbidities:** Diabetes, Hypertension, Obesity, COPD, etc.
*   **Clinical Status:** Pneumonia, Intubation, and ICU admission.
